Du téléphone au Short

Importez un JSON ou chargez le modèle Voyageur. Modifiez les scènes, les plans et leur narration anglaise. Consultez la validation avant l’export.

Conserver votre travail

Les projets sont enregistrés dans ce navigateur. Exportez régulièrement le JSON complet : un effacement du stockage ou une autre adresse ne permet pas de retrouver ces projets.

Les champs inconnus restent dans l’export complet. La copie pour rendu les retire explicitement, avec la liste affichée dans la validation. Le projet original reste intact.

Chronologie

Les scènes sont contiguës. Leur durée est arrondie à l’image. Déplacer un plan conserve son ancrage narratif ; corrigez ses temps si nécessaire. Répartir les plans remplace explicitement les ancrages par des temps réguliers.

Générer dans Colab

  1. Exportez votre JSON.
  2. Ouvrez le notebook ci-dessous dans Chrome Android, choisissez une session CPU Python 3.12 et lancez l’installation.
  3. Importez le JSON depuis vos téléchargements. Le notebook conserve l’original et prépare une copie compatible.
  4. Exécutez Kokoro puis Remotion. Téléchargez le MP4 avant la fin de la session.

Ouvrir Editor-Colab

Aucune clé API payante. Colab requiert un compte Google et ses ressources gratuites dépendent de la disponibilité. Une narration trop longue doit être raccourcie ou sa scène allongée. Les ancrages vocaux affichés ici sont estimés ; Colab vérifie les mots réels.

Publication GitHub Pages

Après fusion volontaire de la PR : Settings → Pages → Source : Deploy from a branch → main → /docs → Save. Aucun workflow à créer. Le JavaScript est déjà compilé dans le dépôt.

Le notebook référence la branche de PR pour être testable avant fusion ; ensuite main peut remplacer cette référence. Consultez la documentation complète.
